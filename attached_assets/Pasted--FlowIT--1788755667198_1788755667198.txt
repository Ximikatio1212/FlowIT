### 2. Рабочая система заявок

Главная задача — сделать полностью рабочую систему заявок.

Форма заявки уже есть на сайте. После заполнения пользователь должен пройти существующее окно согласия на обработку персональных данных.

После подтверждения согласия:

1. Frontend отправляет данные через POST на `/api/leads`.
2. Backend валидирует данные.
3. Backend сохраняет заявку в PostgreSQL.
4. После успешного сохранения отправляет уведомление в Telegram-бот.
5. Только после успешного сохранения в PostgreSQL показывать пользователю сообщение об успешной отправке.

Не имитируй отправку через JavaScript.

Если PostgreSQL недоступна или произошла ошибка сохранения, не показывай сообщение об успешной отправке.

### 3. PostgreSQL

Подключи PostgreSQL через переменную окружения:

`DATABASE_URL`

Не хардкодь пароль, логин или строку подключения в коде.

Создай таблицу `leads`:

* `id` — SERIAL или UUID, primary key
* `name` — имя клиента
* `company` — компания
* `business_direction` — направление бизнеса
* `phone` — телефон / WhatsApp
* `task` — описание задачи
* `budget` — примерный бюджет
* `status` — по умолчанию `new`
* `created_at` — дата и время создания

Сделай автоматическое создание таблицы при запуске приложения, чтобы мне не приходилось вручную создавать SQL-таблицу.

Используй параметризованные SQL-запросы или PostgreSQL ORM/драйвер. Не собирай SQL через конкатенацию пользовательских данных.

База должна быть подготовлена так, чтобы впоследствии весь проект можно было без проблем перенести с Replit на отдельный VPS.

### 9. Подготовка к переносу на VPS

Код должен быть независимым от Replit настолько, насколько это возможно.

Не используй специфичные функции Replit, без которых приложение не сможет работать на обычном Linux VPS.

Приложение должно запускаться обычной командой Node.js и слушать порт из переменной окружения:

`PORT`

Например:

`process.env.PORT || 3000`

Не привязывай PostgreSQL к каким-либо исключительно Replit-функциям.

В будущем проект должен переноситься по схеме:

`Replit → VPS → Node.js + PostgreSQL + Nginx`

без переписывания backend.
